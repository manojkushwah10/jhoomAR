# JhoomAR admin guide

*Written for the shop owner. Updated as each part of the admin panel is built.*

## Signing in

1. Open `https://<your-site>/admin` on a laptop or phone.
2. Type your email and password, then tap **Sign in**.
3. If you type the wrong password 5 times in a minute, wait one minute and try again.

Forgot your password? Ask your developer to reset it (they run one command).
